# Ruidrive Extractor & Safelink Bypass

Alat otomatis untuk membongkar link unduhan light novel / manga dari situs **Ruidrive** dan membypass safelink **Ruisafe**.

## File:
* `AGENTS.md` - Panduan instruksi untuk agen AI Antigravity saat menjalankan tugas ini di PC lain.
* `extractor.py` - Skrip Python mandiri (hanya memakai modul bawaan Python 3).

## Cara Pakai Cepat:
```powershell
# Bypass 1 link ruisafe
python extractor.py "<link_ruisafe>"

# Ekstrak semua volume dari halaman seri
python extractor.py "https://www.ruidrive.com/2021/10/kono-subarashii-sekai-ni-shukufuku-wo.html"
```
