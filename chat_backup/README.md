# PANDUAN PEMULIHAN CHAT ANTIGRAVITY DI PC LAIN

Folder ini memuat arsip lengkap sesi percakapan Antigravity ini (`dfaefe40-f699-4276-8717-cb4f8030016c`), mencakup seluruh log, artefak, transcript JSONL, instruksi, dan riwayat terjemahan novel.

## Cara Menggunakan di PC Baru / PC Lain:

1. **Clone repository ini di PC baru**:
   ```bash
   git clone https://github.com/pangestuyoga081/antigravity-novel-engine.git
   cd antigravity-novel-engine
   ```
2. **Jalankan script pemulihan otomatis**:
   - Cukup klik 2x file:
     `chat_backup\RESTORE_CHAT_KE_PC_INI.bat`
   - File ini akan otomatis mengekstrak seluruh arsip `antigravity_chat_session.zip` ke folder:
     `%USERPROFILE%\.gemini\antigravity\brain\dfaefe40-f699-4276-8717-cb4f8030016c\`
3. **Buka Aplikasi Antigravity**:
   - Riwayat percakapan ini akan langsung muncul dan bisa dilanjutkan secara mulus di PC tersebut!
